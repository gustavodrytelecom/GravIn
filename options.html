Vídeo

Como usar

  1. Abra o DevTools (F12) e ative o modo dispositivo (Ctrl+Shift+M).
  2. Selecione o dispositivo/resolução.
  3. Clique no ícone do GravIn → Iniciar gravação (ou Alt+Shift+R).
  4. Clique de novo para parar. O vídeo é salvo na pasta acima.
